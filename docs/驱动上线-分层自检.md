# 驱动上线：分层自检（"装好了但试不了"怎么定位）

装好了不等于通。整条链是五层，任何一层断都会表现成"按了没反应"。
从下往上逐层验，**哪一层先不通过，问题就在那一层**，不要跳着改。

| 层 | 验什么 | 命令 / 操作 | 通过的样子 | 不通过先看 |
| --- | --- | --- | --- | --- |
| L0 供电 | 手 12V、臂控制柜 | 万用表量航插 1/2 脚 | 12.0–12.2 V，手有上电反应 | 电源开关、线序、0.75 mm² 是否压紧 |
| L1 CAN | 手的心跳 | `python scripts/can_watch.py --seconds 5` | 每秒几百帧，ID `0x64/0x65` | 适配器被占用、驱动、120 Ω 终端 |
| L2 手 | 六指状态 | `python -m handlink serve --bus can` 开 `/state` | `calibrated: true`，角度不是全 0 | 等 15 s 校准；心跳 `calib&0x08` |
| L3 网络 | 臂的控制口 | `ping 192.168.5.1`、`Test-NetConnection 192.168.5.1 -Port 29999` | ping 通、端口开放 | PC 网段、臂是否 TCP 模式、防火墙 |
| L4 臂 | 只读 → 小位移 | `python -m handlink arm --ip 192.168.5.1 --check` | 打印 RobotMode / GetPose / GetAngle | 见下方报错表 |
| L5 合体 | 抓取流程 | `python -m handlink pick --ip … --bus can --speed 10` | 八个步骤依次出现 | 回到 L2/L4 单独验 |

## 今天就能做的（不需要任何硬件）

```bash
python -m handlink pick --preview     # 只算距离和耗时
python -m handlink pick               # 整条流程在仿真臂 + 仿真手上跑一遍
python -m handlink arm --pose 400,0,250,180,0,0 --linear --speed 30
```

跑通这三条，说明软件链路（坐标、时序、互锁、日志）是好的——**这样就排除了"代码问题"**，
剩下的只可能是 L0–L4 里某一层的硬件/网络。

## 接真机的推荐顺序

1. **只读**：`arm --check`，不 enable、不动；确认能读到位姿。
2. **单轴小动**：`arm --enable --speed 10 --pose …`，只走 20–30 mm，人在急停旁边。
3. **空跑抓取**：`pick --speed 10`，手上不夹东西，看时序和互锁。
4. **带件**：`--force 1.0`，先纸杯/海绵，再硬物。

## 报错对照表

| 现象 / 报错 | 大概率原因 | 处理 |
| --- | --- | --- |
| `连不上 192.168.5.1:29999` | 网段不对 / 没插网线 / 臂没上电 | PC 设 `192.168.5.100/24`；网线插 DSC 的 LAN 口 |
| `Control Mode Is Not Tcp` | 臂不在 TCP 控制模式 | 示教器或 DobotStudio → 控制模式切 TCP |
| `臂没有回复（超时）` | 29999 被别的程序占用（DobotStudio 也在连） | 关掉其他客户端，只留一个 |
| `/state` 角度全 0、`calibrated=false` | 手还在校准 / 12V 不足 | 等 15 s；量电压；看心跳 `calib` 位 |
| 手合到一半停住（约 118°） | 电流限流触发 I-LIM | 把 `--force` 提到 1.0 A |
| `OpenDevice => 0` | USB-CAN 被占用 | 停服务 / 关厂商软件 / 拔插 USB |
| `手没有合到位…已中止，未抬升` | 互锁生效（正常保护） | 查电流与手指是否被卡 |

## 官方连接步骤（Nova 5，据越疆官方文档整理）

**① 上电与急停**

- 控制柜吃 **30–60 V DC**，不是直接插 220 V：用原配适配器，或 48 V 开关电源
  （越疆示例是 MEAN WELL HRP600N3-48）。正负极别接反，PE 接地。
- 急停按钮接到柜上的急停端子（常闭），压一下应立刻断使能。

**② 臂本体**

- 本体出来的 3 m 电缆插控制柜的 Robot 接口，**不可自行延长**；
- 末端工具（我们的转接板 + LG-603）走法兰 4×M6 + Φ6 定位孔。

**③ 联网（两条路，任选）**

| 方式 | 做法 | 默认值 |
| --- | --- | --- |
| 有线（推荐） | 网线插柜的 LAN1，另一端插 PC；PC 设静态 IP | PC `192.168.5.10/24`，臂 `192.168.5.1` |
| 无线 | 把随机附带的 USB 无线模块插到柜上，PC 连热点 | SSID `Dobot_WIFINV5-xx`，密码 `1234567890` |

无线这条是官方支持的应急方案，好处是不用改 PC 网卡；坏处是 29999 的延迟会抖，
**真做抓取时用有线**。

**④ 软件连上**

1. 装 **DobotStudio Pro v2**（v4 连不上 Nova；灰色外壳的新款除外，需按随机文档）；
2. 启动后自动发现 Nova → 点 `Connect` → 显示 `Online`；
3. 在 Studio 里把控制模式切到 **TCP/IP**——不切，29999 会回 `Control Mode Is Not Tcp`；
4. 命令行验证：`ping 192.168.5.1`、`Test-NetConnection 192.168.5.1 -Port 29999`。

**⑤ 编程连接**

- 控制口 29999、反馈口 30004；**同一时刻只允许一个客户端**，Studio 开着时脚本连不上；
- 官方 Python 库：<https://github.com/Dobot-Arm/TCP-IP-CR-Python-V4>；
- 本项目：`python -m handlink arm --ip 192.168.5.1 --check`（只读）。

**⑥ 手（LG-603）单独一条链**

- 12 V / 峰值 5 A 独立电源 + CAN 1 Mbps → GCAN USBCAN-I → PC；
- **不要**从臂末端 IO（24 V×0.5 A）取电。

出处：Nova 系列用户指南（电源、末端 IO、法兰）、[DobotStudio Pro 连接步骤](https://techshare.co.jp/faq/dobot/nova-dobotstudiopro-setup.html)、
[TCP-IP-Python-V4 官方库](https://github.com/Dobot-Arm/TCP-IP-CR-Python-V4)、越疆支持 400-800-7266。

## 安全（写在最前）

- 第一次移动：`SpeedFactor ≤ 10%`，工作空间内不要放手。
- 急停接在 DSC 急停口，人站着急停够得着。
- 手闭合前确认手指中间没有线缆；断电后手会变软，注意别磕。
- 任何异常先 `/stop` 或 `arm --stop`，再排查，不要连续复位。
