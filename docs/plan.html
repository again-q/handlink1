场景做法
第一次动 / 改完点位速度 ≤60、电流 ≤0.3 A、单指逐个验证
电流上限拇指 0.8 A，其余 3.5 A。数值越大不代表越安全
卡滞 / 异响 / 异常电流立刻停，排查机械干涉，别反复复位
臂在动速度倍率 ≤30%，先空跑轨迹再放物
观众离设备 1.5 m，地面贴线；有人靠太近直接急停
校准只在 CAN 稳定、负载卸掉、动作停止时做；过程中不许断连接
?卡住了怎么办
现象先查什么
scan 看不到 COM换根线、装 CH340 驱动、换个 USB 口（别用 hub）
CAN 打开失败适配器没插好 / 被 LG-603 占着 / 换通道试试
点了发送但手不动左右手选反、电流太小、连接其实没打开
动作方向反了左右手类型、手套的左右设置
校准超时卸掉负载、检查 CAN 稳定性，校准中不能断连接
提示过流 / 卡滞立即停，人工检查机械干涉和供电
位置/计数异常复位后从最小角度低速验证，别直接跑动作
✓验收：三组实测数据
实验怎么做记什么
极限位每根手指 0° 和最大角各 5 次能不能到位、有没有异响
重复性同一个点位下发 20 次实际角度的最大值−最小值
握力-电流电流 0.3 / 0.5 / 0.8 各抓一次打不打滑、物体有没有变形
这三组数据手册里没有，但决定了它能不能做精密活——也是你们参赛时最硬的材料。
