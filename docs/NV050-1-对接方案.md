> 2026-11-12 · 结论：**能装、能控，但要解决三件事**——法兰转接板、12V 供电、CAN 走线。

## 2. 和 LG-603 合不合

| 检查项 | 结论 |
| --- | --- |
| 负载 | LG-603 510 g + 转接板约 0.3 kg，占 5 kg 的 16%，**余量充足** |
| 抓取力反作用 | 握持 85 N 是手内部受力；搬运时力矩取决于工件，5 kg 级臂够用 |
| 末端法兰 | 4×M6 + Φ6 定位孔，做一块转接板即可；LG-603 背面安装孔位**需按实物/厂家 CAD 确认** |
| 控制 | 臂走 TCP/IP（29999 控制、30004 反馈）；手走 CAN，两套独立，PC 侧协同 |
| 供电 | ⚠️ 手要 **DC12V、峰值 5 A**；臂末端 IO 只有 24 V×0.5 A（12 W），**带不动**，必须单独走 12 V |
| 布线 | ⚠️ CAN 双绞线要从 PC/适配器一路走到手上，随臂运动，需要拖链或波纹管 + 应力释放 |

## 3. 三件要解决的事

### 3.1 法兰转接板（最花时间）

- 臂侧：4 个 M6 通孔（按 ISO 9409 分布）+ Φ6 定位销孔。
- 手侧：LG-603 背部安装孔（203×82×40 mm 机身），孔距与螺纹规格以实物为准。
- 建议 6061-T6、厚 8 mm、阳极氧化；中间留 Φ30 过线孔，让 CAN + 12V 从腕部穿出。
- 精度：转接板平面度 ≤0.05 mm，否则 ±0.05 mm 的臂精度会被吃掉。

### 3.2 12V 供电

- 独立 12 V / 8 A 电源（明纬 LRS-100-12 或 GST120A12），别从臂的 IO 取电。
- 电源放控制柜旁，12 V 与 CAN 一起走 4 芯屏蔽线（2×0.75 mm² 电源 + 120 Ω 双绞 CAN）。
- 末端用 4 芯航插（GX12/HR10A）过渡，方便拆装。

### 3.3 CAN 走线

- 方案 A（便宜）：GCAN USBCAN-I 留在 PC 端，CAN 线随臂走，1 Mbps 下 5 m 内没问题。
- 方案 B（干净）：买一台 CAN 转以太网/WiFi 网关放在臂座，PC 走网线，臂上只有 2 根 CAN。
- 注意：手每秒约 3000 帧心跳，网关要能扛住，且**同一时刻只能一方占用适配器**
  （这条 handlink 里已经踩过坑）。

## 4. 代码怎么接

现有 `handlink` 已经把「总线」抽象出来了，加一个臂适配层即可：

```
PC
 ├─ handlink（CAN → LG-603）        已有
 └─ arm_dobot.py（TCP 29999/30004） 新增
        └─ pick.py：到位 → 合手 → 抬起
```

- 臂侧：socket 连 `29999` 发 `MovJ/MovL/SpeedFactor`，`30004` 读实时位姿做"到位判断"；
  官方有 ROS2 驱动（支持 nova2/nova5）：<https://github.com/Dobot-Arm/TCP-IP-ROS-6AXis>
- 手侧：直接用 `handlink` 的 `/pose` 或 `Hand` 类。
- 时序：`MovL 到预抓取 → 等到位 → 手合到 1.0 A 限流 → 等 300 ms → 抬升 → 记录`。
- 建议先做 `--dry-run`：臂不动，只打印轨迹与手部指令。

## 5. 安全

- 5 kg 协作臂 + 85 N 握力，夹手很疼：先设 `SpeedFactor ≤ 30%`，示教时手离远。
- 急停接 DSC 的急停口；软件侧加"手未闭合禁止抬升"的互锁。
- 首次上电：手单独验证（已有流程），再装臂，再空载跑轨迹，最后才带工件。

## 7. 要跟厂家/社团确认的

1. LG-603 背部安装孔的实际孔距、螺纹（有 CAD 最好）；
2. 这台 Nova 5 是 DSC 还是 CCBox 控制柜、固件版本（决定 29999 指令集）；
3. 臂的安装方式（桌面/立柱/倒装）与工作空间，决定拖链长度；
4. 社团是否允许在臂上打孔/加装——转接板方案不需要动臂本体，只借原法兰孔。

## 8. 怎么连（照着做）

### 8.1 连线总图

```
220V ── LRS-100-12 ── 12V/GND ─┐
                                ├── 4 芯屏蔽线（2×0.75 电源 + 120Ω 双绞 CAN）
GCAN USBCAN-I ── CAN_H/CAN_L ──┘        │
        │ USB                            ▼
       PC ────── 网线 ────── DSC 控制柜 ── 臂 ── 法兰 ── 转接板 ── LG-603
                                 (192.168.5.1)
```

一根线都不许从臂末端 IO 取电（24V×0.5A 只有 12W，手峰值要 60W）。

### 8.2 机械（1 小时）

1. 转接板 4×M6×16 拧到臂法兰，Φ6 销钉定位；
2. 手背对准转接板孔位，M3/M4 螺钉固定（孔距待量）；
3. 4 芯线从转接板中间 Φ30 孔穿出，末端留 15 cm 服务环；
4. 手线沿臂外侧走，每 20 cm 一个扎带固定，**J5/J6 轴附近留 S 形余量**。

### 8.3 电气（1 小时）

| 线 | 从 | 到 | 备注 |
| --- | --- | --- | --- |
| 220V L/N/PE | 插座 | LRS-100-12 输入 | 带开关 |
| +12V | 电源 | 航插 1 脚 | 0.75 mm² |
| GND | 电源 | 航插 2 脚 | 与 CAN 地共点，只共一次 |
| CAN_H | GCAN 的 CAN_H | 航插 3 脚 | 双绞 |
| CAN_L | GCAN 的 CAN_L | 航插 4 脚 | 双绞 |
| USB | GCAN | PC | — |

细节：
- 手内部一般已有 120 Ω 终端，**别再并在手上**；总线两端各一个终端，另一端在 GCAN 侧（部分型号有拨码开关）。
- 12V 先空载量一遍（11.8–12.2 V）再接入手。
- 手是 DC12V±10%，5A 峰值；电源留 30% 余量。

### 8.4 网络（20 分钟）

1. PC 网卡设静态 IP：`192.168.5.100 / 255.255.255.0`；
2. 网线插 DSC 的 LAN 口，`ping 192.168.5.1` 通；
3. 浏览器开 DobotStudio（或 APP）连上，先只读位姿，不动；
4. 命令行验证控制口：`Test-NetConnection 192.168.5.1 -Port 29999`。

### 8.5 手先通，再上臂（顺序别反）

```bash
python -m handlink scan                 # 能看到 GCAN
python -m handlink serve --bus can      # 起服务
# 浏览器 http://127.0.0.1:8766/demo → 点"张开/握拳"确认手正常
```

手确认无误后，再单独验证臂：29999 发 `SpeedFactor(20)`、`MovJ` 小角度、`EnableRobot()`。

### 8.6 合在一起

```bash
python -m handlink serve --bus can          # 一个终端：手
python scripts/pick.py --dry-run            # 另一个终端：只打印轨迹
python scripts/pick.py --speed 20 --force 1.0   # 真跑：到位→合手→抬升
```

判断"到位"用 30004 反馈，别用 `sleep`；合手用 1.0 A 限流（0.6 A 会卡在 118°）。

### 8.7 上电/断电顺序

- 上电：手 24V → 等校准（`/state` 里 `calibrated=true`）→ 臂控制柜 → PC 连网 → 起服务。
- 断电：先 `/stop` → 臂回安全位 → 手张开 → 断手电 → 断柜电。

### 8.8 更省线的方案 B（可选）

臂座上放一台迷你主机/树莓派 + USB-CAN，`handlink` 跑在上面，PC 只走 WiFi 调 HTTP：
臂上只剩 12V 两根线，CAN 不再穿臂。成本 +500–800 元，调试反而更清爽。
