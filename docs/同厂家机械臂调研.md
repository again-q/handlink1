# 同厂家机械臂调研（中科灵犀）

> 调研时间：2026-11-12 · 来源：厂家官网、公开报道、第三方产品库
> 结论先说：**中科灵犀没有单独卖的"裸机械臂"产品**。它的臂只作为
> 「轮式人形机器人 LSRobot-002」和「手眼臂协同系统」的一部分出货，
> 官网产品中心里能下单的只有灵巧手和整机。

---

LG-603 就是这家"连杆灵巧手"系列里的工业款（6 主动 + 10 被动自由度、
≤510 g、静态负载 25 kg、握持力 85 N、CAN 接口、DC12V）。
同系列还有 LG-601、LG-1501，绳驱线是 SQ-1503。

## 2. 它家的"臂"到底长什么样

### 2.1 LSRobot-002 —— 轮式双臂人形（唯一公开参数表的带臂产品）

| 参数 | 数值 |
| --- | --- |
| 形态 | 轮式双臂，双轮差速 |
| 臂 | 双 6 轴（参数表另写"单机械臂自由度 7"，**厂家自己口径不一致，需确认**） |
| 单臂负载 | 10 kg |
| 整机 | 约 150 kg，1670×550×660 mm（升高后） |
| 移动 | 0–1.5 m/s，转弯半径 430–500 mm，爬坡 10°，越障 <30 mm |
| 续航 | 48V 40Ah，约 6 h |
| 通信 | WIFI（整机层面；臂本体协议未公开） |
| 末端 | **适配连杆灵巧手**——即 LG 系列，LG-603 可直接装 |
| 感知 | 视觉 + 触觉 |

### 2.2 手眼臂协同系统（2 款，未单独列型号）

- 双臂 + 3D 视觉 + "手-眼-臂-脑"闭环，公开说法是 10 s 左右完成
  「识别 → 抓取 → 规整 → 固定」。
- 展示案例：双臂泡茶（已出口约 10 套）、非标件柔性上料。
- 没有独立参数页，臂展 / 重复精度 / 负载 / SDK 都要问销售。

### 2.3 产品矩阵口径（2026-10 报道）

5 款连杆灵巧手 + 2 款绳驱灵巧手 + **2 款手眼臂协同系统** + 1 款轮式人形机器人。
也就是说：臂是"系统"里的部件，不是独立 SKU。

## 3. 价格与可得性

- 官网、第三方数据库（RoboAtlas / RobotMap）都**没有臂的报价**，只有
  "询价"。灵巧手侧有经销商标价（如 SQ-1503 约 USD 16,500），臂没有。
- 想买臂只有三条路：
  1. 买 LSRobot-002 整机（150 kg，轮式，适合产线/巡检，不适合课桌）；
  2. 买手眼臂协同系统（按场景定制，含视觉与算法）；
  3. 直接问销售：**臂能不能单卖 / 能不能只买臂 + 法兰**（大概率可以谈，但属于定制）。

## 4. 询价时必须问清的 8 件事

1. 单臂能否单独出货？最小配置是什么（臂 + 控制柜 + 示教器）？
2. 臂展、重复定位精度、单臂负载、额定/峰值速度；
3. 末端法兰标准（ISO 9409-1-50-4-M6？）与 LG-603 的转接件是否现成；
4. 控制接口：ROS2 / TCP-IP / EtherCAT？有没有 Python SDK、能不能读关节力矩；
5. 与 LG-603 的分工：手部 CAN 由谁控？臂控器能否透传手部指令（我们要接着自己的 handlink）；
6. 安全：急停回路、安全等级（PLd / ISO 10218-1）、碰撞检测；
7. 供电与气路：臂 48V/220V？手是 DC12V 5A，需不需要单独电源；
8. 价格、交期、是否含调试与培训；教育/科研有没有折扣。

## 5. 对我们项目的判断

- 目标如果是"LG-603 装到臂上做抓取实验"，同厂家最省事的是 **LSRobot-002 的臂**，
  因为末端明确适配连杆灵巧手，法兰和电控大概率已经配好。
- 但整机 150 kg、轮式、按产线设计，**不适合社团桌面演示**；如果只要一条臂，
  得走定制询价，周期和价格都不确定。
- 备选（不属于"同厂家"）：桌面级 6/7 轴臂（越疆、遨博、UR 等）+ 定制法兰，
  我们现有的 `handlink` 里 CAN 层不用改，只需在臂侧加一层运动接口。
